# MENTOXXTOOL

A simple Termux utility tool with an animated MENTOXXTOOL banner and menu.

## INSTALL

Run this command in Termux:

curl -sS https://raw.githubusercontent.com/aimentoxx-tool/MentoxxTool/main/install.sh | bash

After installation, start the tool:

mentoxxtool

## FEATURES

- Animated MENTOXXTOOL banner
- Device Information
- ADB Tools
- Battery Information
- Storage Information
- ADB Shell
- Mi Assistant
- Firmware ZIP Extractor
- Unlock Status Checker

## REQUIREMENTS

The installer automatically installs:

- Python
- Android Platform Tools (ADB)
- unzip

## ADB

For ADB features, enable USB debugging and authorize the connected device.

## NOTE

Unlock Status only checks device properties. It does not bypass manufacturer authorization or security protections.
